Confidentialité

En bref : vos photos restent sur votre appareil. Prism ne contient ni publicité, ni pisteur, ni mesure d’audience.

Vos photos

Les photos que vous ouvrez, vos retouches, votre photothèque et vos réglages sont enregistrés uniquement sur votre appareil : sur le disque dans l’application pour Mac et Windows, dans le stockage du navigateur pour la version en ligne. Prism ne les envoie à aucun serveur.

L’intelligence artificielle

Les outils d’IA (gomme IA, détection du sujet et du ciel, remplissage génératif…) tournent sur votre appareil. Vos photos ne sont envoyées à personne pour être analysées. Les modèles d’IA sont téléchargés une fois depuis la page GitHub de Prism, la première fois que vous utilisez l’outil.

Ce qui passe par Internet

  • Ce site et la version en ligne sont hébergés par GitHub Pages. Comme tout hébergeur, GitHub reçoit votre adresse IP quand vous chargez une page.
  • La police d’écriture (Geist) est chargée depuis Google Fonts, qui reçoit donc aussi votre adresse IP.
  • Les téléchargements (l’application, les modèles d’IA, la recherche de la dernière version) passent par GitHub.

Prism n’envoie rien d’autre : pas de statistiques d’utilisation, pas de rapport d’erreur automatique.

Le compte Prism (bientôt)

Un compte facultatif permettra de synchroniser vos photos entre vos appareils. Il n’est pas encore ouvert. Quand il le sera, voici ce qui sera enregistré :

  • votre adresse e-mail, votre mot de passe sous forme chiffrée (jamais en clair), et, si vous les ajoutez, un nom et une photo de profil ;
  • la liste de vos appareils connectés (nom et type d’appareil) ;
  • pendant la synchronisation, vos photos transitent par le serveur 24 heures au plus, puis sont effacées. Quand vos deux appareils sont allumés en même temps, elles passent directement de l’un à l’autre ;
  • la liste des modifications à synchroniser (sans les photos), gardée 30 jours.

Le serveur sera hébergé par Cloudflare. Vous pourrez supprimer votre compte et ces données. Cette page sera mise à jour avant l’ouverture du compte.

Le compte d’essai

Le compte d’essai disponible aujourd’hui reste entièrement sur votre appareil : rien n’est envoyé.

Vos droits

Vous pouvez à tout moment effacer vos données : supprimez les photos depuis la photothèque (puis videz la Corbeille), ou désinstallez l’application. Dans la version en ligne, effacer les données du site dans votre navigateur supprime tout. Pour toute question, écrivez sur la page du projet.
