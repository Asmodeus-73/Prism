Confidentialité

Vos photos restent sur votre appareil. Ni publicité, ni pisteur, ni mesure d’audience.

Vos photos

Les photos que vous ouvrez, vos retouches, votre photothèque et vos réglages restent sur votre appareil : sur le disque pour l’application, dans le navigateur pour la version en ligne. Aucun serveur ne les reçoit.

L’intelligence artificielle

Les outils d’IA (gomme IA, détection du sujet et du ciel, remplissage génératif…) tournent sur votre appareil. Aucune photo n’est envoyée pour analyse. Chaque modèle d’IA se télécharge une fois depuis GitHub, au premier usage.

Ce qui passe par Internet

  • Ce site et la version en ligne sont hébergés par GitHub Pages. GitHub reçoit votre adresse IP à chaque page chargée, comme tout hébergeur.
  • La police d’écriture (Geist) vient de Google Fonts, qui reçoit votre adresse IP.
  • Les téléchargements (l’application, les modèles d’IA, la recherche de la dernière version) passent par GitHub.

Rien d’autre : ni statistiques d’utilisation, ni rapport d’erreur.

Le compte Prism (bientôt)

Un compte facultatif permettra de synchroniser vos photos entre vos appareils. Il n’est pas ouvert. Voici ce qu’il enregistrera :

  • votre adresse e-mail, votre mot de passe chiffré et, si vous les ajoutez, un nom et une photo de profil ;
  • la liste de vos appareils connectés (nom et type d’appareil) ;
  • pendant la synchronisation, vos photos restent sur le serveur 24 heures au plus, puis sont effacées. Si vos deux appareils sont allumés, elles passent de l’un à l’autre sans serveur ;
  • la liste des modifications à synchroniser (sans les photos), gardée 30 jours.

Le serveur sera hébergé par Cloudflare. Vous pourrez supprimer votre compte et ces données. Cette page sera mise à jour avant l’ouverture du compte.

Le compte d’essai

Le compte d’essai reste sur votre appareil : rien n’est envoyé.

Vos droits

Pour effacer vos données, supprimez les photos depuis la photothèque (puis videz la Corbeille), ou désinstallez l’application. En ligne, effacez les données du site dans le navigateur. Pour une question, écrivez sur la page du projet.

Dernière mise à jour : novembre 2026.
